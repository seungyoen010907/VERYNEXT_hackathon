# AI 점포 양도양수 에이전트

양도인의 민감한 영업정보는 공개 범위 안에서만 보여주고, 양수인의 AI 에이전트가 여러 양도인의 AI 에이전트와 정보를 주고받아 점포의 실제 수익성과 인수 적합성을 비교하는 서비스예요. (NEXT 해커톤)

- 무엇을 만드나: `docs/PRD.md` · 어떻게 보이나: `docs/DESIGN.md` · 어떻게 동작하나: `docs/API.md`

## 실행

```bash
cp env.example .env.local   # OPENAI_API_KEY, OPENAI_MODEL, SUPABASE_URL, SUPABASE_SECRET_KEY 채우기
npm install
npm run dev                 # http://localhost:3000
```

Supabase SQL Editor에서 `supabase/schema.sql`을 한 번 실행해야 해요 (여러 번 실행해도 안전).

## 시연 순서 (샘플 데이터)

1. **매물** → "샘플 데이터로 시연하기": 양도인 A(샘플분식)·B(샘플카페)·C(샘플국밥) 매물과 양수인 조건이 만들어져요. 모두 가상 자료예요.
2. 헤더에서 **양수인**을 고르고 매물 3개를 "비교에 추가" → **AI 실사 시작**.
3. AI 실사 센터에서 매물마다 질문 상태를 봐요. "NDA 필요"가 뜨면 **NDA 테스트 동의 후 다시 묻기**.
4. 헤더에서 **양도인 A**로 바꾸고 매물 → 구매자 요청 관리에서 **승인** → 양수인 AI 질문에 자동으로 답이 가요.
5. 다시 **양수인**으로 바꿔 AI 실사 센터 → "AI 분석 만들기", **비교표**, 매물별 **AI 실사 리포트**를 봐요.

로그인 대신 헤더에서 데모 사용자를 고르는 시연용 방식이에요. NDA는 "테스트 동의(법적 효력 없음)"로만 기록해요.
